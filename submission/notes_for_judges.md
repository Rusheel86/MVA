# Notes for judges (optional field on the Track 2 form; about 1,000 characters)

Start with the "At a glance" block and section 3 of the report. The idea: when no approved drug fits the protein, treat each allele. The stop allele (read-through: azithromycin, amlexanox) and the missense allele (niacin) are tested together, in the child's own cells, with one RT-PCR amplicon that also phases the alleles and supplies the evidence to reclassify the second one.

Every citation was checked against its source. The report says what it does not know (whether read-through delivers enough protein) and lists what would falsify each hypothesis. The triage is checked on 16 published alleles in unrelated genes (a sanity check, not proof). The 131-allele atlas and the code are reusable. The pipeline writes the report, so the repository reproduces every number.

Hypotheses for follow-up only; no treatment advice.
